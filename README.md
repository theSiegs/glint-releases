# Glint releases

Signed APKs of Glint, a live-tiles home screen for Android built on
[Kvaesitso](https://github.com/MM2-0/Kvaesitso) (GPL-3.0). Glint is licensed under the GPL-3.0 as well.

Glint checks this repository's latest release to update itself. Each release's APK is signed with the
same key; Glint refuses an update signed with any other key.

The source code for any release is available on request (GPL-3.0 §6): open an issue in this repository.
